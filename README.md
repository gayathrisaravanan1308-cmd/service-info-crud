# Service Info CRUD App

Flask + MySQL use panni seitha simple CRUD application.

## Features
- Add Service
- View All Services
- Edit Service
- Delete Service

## How to Run
1. pip install flask pymysql
2. MySQL la qrCode database create pannunga
3. app.py la unga MySQL password-a podunga
4. python app.py run pannunga

## Tech Used
- Python Flask
- MySQL
- HTML, CSS
